# AR Globe

> 日本語のREADMEはこちらです: [README.ja.md](README.ja.md)

An AR (Augmented Reality) globe project that allows users to interact with a virtual globe in real-time.

## Demo
[AR Globe Demo](https://code4fukui.github.io/ar-globe/)

## Features
- Displays a virtual globe with country borders and details
- Supports interactive rotation of the globe using hand gestures
- Allows for customization of the globe, such as highlighting specific countries

## Requirements
- WebXR-enabled browser

## Usage
1. Open the [AR Globe Demo](https://code4fukui.github.io/ar-globe/) in a WebXR-enabled browser.
2. Grant the necessary permissions to access the device's sensors.
3. Use hand gestures to rotate and interact with the virtual globe.

## Data / API
The project uses data from the [Natural Earth GeoJSON](https://github.com/code4fukui/natural-earth-geojson/) repository.
