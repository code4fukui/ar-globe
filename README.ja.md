# AR Globe

ユーザーがリアルタイムでインタラクティブに操作できる、AR（拡張現実）地球儀プロジェクトです。

## デモ
[AR Globe デモ](https://code4fukui.github.io/ar-globe/)

## 機能
- 国境や詳細情報を備えたバーチャル地球儀を表示
- ハンドジェスチャーによる地球儀のインタラクティブな回転操作をサポート
- 特定の国のハイライトなど、地球儀のカスタマイズが可能

## 要件
- WebXR対応ブラウザ

## 使い方
1. WebXR対応ブラウザで[AR Globe デモ](https://code4fukui.github.io/ar-globe/)を開きます。
2. デバイスのセンサーへのアクセスに必要な権限を許可します。
3. ハンドジェスチャーを使用して、バーチャル地球儀を回転させたり操作したりします。

## データ / API
本プロジェクトでは、[Natural Earth GeoJSON](https://github.com/code4fukui/natural-earth-geojson/)リポジトリのデータを使用しています。
